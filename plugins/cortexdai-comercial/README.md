# CortexDAI · Comercial

Skills para leer las ventas de tu empresa contra la meta, con las cifras verificadas de CortexDAI.

| Skill | Para qué |
|---|---|
| `como-vamos` | Cómo va el mes contra la meta, por sede, y qué productos frenan |
| `plan-para-cerrar-el-mes` | La brecha convertida en acciones con cifra, responsable y fecha |
| `evaluar-un-producto` | Un producto o línea de punta a punta, con veredicto |
| `informe-de-la-semana` | El informe para gerencia en una página |

**Conector:** `https://mcp.cortexdai.dobservability.com/mcp`. Al conectarlo inicias sesión con tu usuario de
CortexDAI y eliges tu ambiente. Solo lee: no cambia nada.

Las skills no traen cifras: todas salen del conector, en cada conversación.
