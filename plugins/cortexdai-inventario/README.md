# CortexDAI · Inventario

Skills para leer el inventario de tu empresa con las cifras verificadas de CortexDAI.

| Skill | Para qué |
|---|---|
| `dinero-detenido` | Cuánto dinero hay en el almacén por antigüedad, dónde está y qué liquidar primero |
| `que-pedir-y-que-no` | Meses de inventario por sede y producto: qué pedir ya, qué dejar de pedir y qué no se vende |

**Conector:** `https://mcp.cortexdai.dobservability.com/mcp`. Al conectarlo inicias sesión con tu usuario de
CortexDAI y eliges tu ambiente. Solo lee: no cambia nada.

Las skills no traen cifras: todas salen del conector, en cada conversación.
